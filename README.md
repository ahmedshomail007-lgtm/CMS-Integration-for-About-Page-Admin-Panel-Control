# CMS-Integration-for-About-Page-Admin-Panel-Control
Successfully developed a Content Management System (CMS) module for the "About Us" section of a web application using the MERN Stack. The system allows administrators to update company information dynamically without modifying the source code.
Technical Stack Used
Frontend: React.js (Hooks, Axios for API calls)

Backend: Node.js & Express.js

Database: MongoDB (Local instance)

ORM: Mongoose

Key Features Implemented
Database Connection: Established a stable connection between the Node.js server and a local MongoDB instance (cms_db).

RESTful API: Created GET and POST routes to retrieve and update company data.

Admin Panel: Built a responsive React form with real-time state management to handle inputs for Company Name, Description, Mission, and Vision.

Data Persistence: Verified that data entered via the UI is correctly stored and retrieved from the abouts collection in MongoDB.
